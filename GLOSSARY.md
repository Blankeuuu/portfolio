# Słownik pojęć (GLOSSARY)

- **GLB (Binary glTF 2.0)** — binarny format przesyłania modeli 3D używany przez przeglądarkowy komponent `<model-viewer>` do interaktywnego podglądu geometrii.
- **Dev Fixture (`isDevFixture`)** — oznaczony obiekt testowy w kolekcji modeli 3D, używany wyłącznie w testach automatycznych i przy `INCLUDE_DEV_FIXTURES=true`, automatycznie wykluczany z produkcyjnej wersji strony.
- **Unified Project Item** — znormalizowana struktura łącząca repozytoria GitHub (`createdAt`) oraz modele 3D (`publishedAt`) we wspólny strumień sekcji `Recent Work`.
- **Canonical Route Key** — neutralny językowo identyfikator trasy (np. `/repos/`, `/models/slug/`), z którego generowane są odpowiadające sobie ścieżki angielskie (`/repos/`) i polskie (`/pl/repos/`).
